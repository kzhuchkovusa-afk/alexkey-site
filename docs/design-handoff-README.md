# Комплект передачи дизайна в разработку — сайт Alex Key

Этот архив — мост между канвасом Claude Design и Claude Code. Канвас удобен вам, чтобы смотреть и править. Claude Code работает с файлами в репозитории, поэтому здесь всё, что он должен видеть, лежит файлами.

## Что внутри

| Файл | Зачем |
|---|---|
| `CLAUDE-CODE-PROMPT.md` | Первое сообщение для Claude Code — скопировать целиком |
| `design/DESIGN.md` | Правила дизайн-системы для разработки: токены, компоненты, страницы, отличия от ТЗ |
| `design/theme.css` | Токены для Tailwind v4: цвета, шрифт, размеры, радиусы |
| `design/tokens.json` | Те же токены для других инструментов (карточки постов, превью) |
| `design/reference/png/` | Эталоны: все 13 досок канваса картинками |
| `design/reference/html/` | Те же доски в HTML — открыть в браузере и посмотреть точные значения |
| `design/fonts/` | Шрифт Schibsted Grotesk и его лицензия (OFL) |
| `docs/TZ-v0.2.pdf` | ТЗ v0.2. Если документ ТЗ обновится — положите рядом свежий экспорт `docs/TZ.md` |

## Как запустить — 5 шагов

1. **Репозиторий.** Создайте на GitHub пустой репозиторий, например `alexkey-site`.
2. **Комплект.** Распакуйте архив в корень репозитория и сделайте коммит.
3. **Claude Code.** Откройте Claude Code в этом репозитории.
4. **Первое сообщение.** Вставьте текст из `CLAUDE-CODE-PROMPT.md`. Сначала Claude Code пришлёт план — это и есть работа «архитектора». Ответьте на вопросы и напишите «ок».
5. **Приёмка по фазам.** После каждой фазы откройте превью на Netlify с телефона, в том числе из Facebook, и сравните с картинками из `design/reference/png`.

## Если дизайн меняется

Правим на канвасе → просим Claude в Design обновить этот комплект → кладём новую версию в репозиторий → пишем Claude Code: «Дизайн обновлён, сверь с эталонами и поправь».

Этот же комплект подходит живому разработчику: ему нужны те же файлы и тот же `DESIGN.md`.
